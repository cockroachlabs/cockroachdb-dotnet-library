Namespace
CockroachDB.DotNet.EntityFramework.Migrations

Migration SQL generator for CockroachDB, extending Npgsql's PostgreSQL generator with CockroachDB-specific DDL overrides: computed columns (STORED only), JSON default fix, and unique_rowid() support.
