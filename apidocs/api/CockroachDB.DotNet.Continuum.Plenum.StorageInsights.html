Read-only Cockroach Plenum storage insights.

Surfaces usage-based storage signals — per-table estimated row counts and, where the running version exposes it, approximate on-disk size — using only customer-safe SHOW surfaces (never crdb_internal, which is restricted in v26.2). Version-tolerant: signals a given version does not expose are returned as null rather than raising, and any query failure degrades to an empty result instead of throwing the whole summary.
