Namespace CockroachDB.DotNet.Continuum.Agent

Classes

AgentToolAttribute

Exposes the annotated method as an agent-callable tool (e.g. for Cockroach Aegis or any MCP client). Only [AgentTool] methods are exposed, and Destructive tools are hidden unless the caller explicitly opts in — least privilege by default.

CrdbAgent

Agent / MCP facade over [AgentTool]-annotated providers.

var agent = CrdbAgent.From(new CrdbOpsTools(dataSource, storageInsights));
var tools = agent.ListTools();                        // MCP tools/list
var result = await agent.InvokeAsync("health", null); // MCP tools/call

Least-privilege: destructive tools are excluded unless AllowDestructive(bool) is enabled. A full MCP stdio/HTTP server is out of scope for this increment; adapt ListTools()/InvokeAsync(string, IReadOnlyDictionary<string, object>?) onto your transport of choice.

CrdbOpsTools

Built-in, safe (non-destructive) AgentToolAttribute tools exposing common CockroachDB operations to an agent: connectivity and Cockroach Plenum storage usage.

ToolDescriptor

A described, agent-callable tool.

ToolRegistry

Reflects over [AgentTool]-annotated methods on provider objects and exposes them as described, invokable tools. Least-privilege: destructive tools are only registered when allowDestructive is set.
