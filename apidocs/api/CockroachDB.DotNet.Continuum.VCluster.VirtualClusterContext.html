AsyncLocal<T>-based Cockroach vCluster context for programmatic use, mirroring RegionContext. When set, VirtualClusterMiddleware (and the OnVirtualCluster(...) execution wrapper) apply the tag/QoS to the transaction. Flows correctly across async/await continuations.
