Namespace CockroachDB.DotNet.Continuum.Aegis

Classes

AegisExhaust

Publishes application-side operational signals ("exhaust") to Cockroach Aegis.

The library sees app-attributed events — serialization retries, circuit trips — that the cluster alone cannot tie back to a specific service/method. Call these convenience methods from your retry/circuit hooks (or wire them into the metrics layer) to feed Aegis. Backed by any IAegisClient (the SimulatedAegisClient by default).

AppEvent

An application-side operational event published to Cockroach Aegis ("exhaust"). The library sees app intent + DB behavior the cluster alone cannot attribute (retry storms, circuit trips), so this feeds Aegis high-signal data.

Finding

A Cockroach Aegis finding: an observation the autonomous-ops agents surfaced about a cluster.

HttpAegisClient

Placeholder for the real Cockroach Aegis HTTP client.

The Aegis API is not yet public, so every operation throws NotSupportedException — callers never silently believe they are talking to a live Aegis. Use SimulatedAegisClient for development and tests.

McpAegisClient

Adapts an IMcpClient to IAegisClient. Aegis is reachable read-only over the Cockroach Continuum Cloud MCP server; this adapter calls the configured tools and parses their text content as JSON into Finding/Recommendation.

McpToolNames

Maps Aegis operations to the tool names an MCP server advertises. The Cockroach Continuum MCP tool contract is not pinned here: names differ by server and may change. Discover them with ListToolsAsync(CancellationToken) and set the ones you need; an unset name throws rather than guessing.

Recommendation

A Cockroach Aegis recommendation: a suggested action tied to one or more findings.

SimulatedAegisClient

In-memory Cockroach Aegis client for local development and tests. Returns a small canned set of findings/recommendations and records every emitted AppEvent so tests (and demos) can inspect the exhaust.

Interfaces

IAegisClient

Client for Cockroach Aegis autonomous database operations.

Read-first: list findings/recommendations the agents produced. Also accepts application "exhaust" via EmitAsync(AppEvent, CancellationToken) so app-attributed signals can inform the agents.

Aegis is preview/EA and its API is not yet public. The default, fully-functional implementation is SimulatedAegisClient; a real HttpAegisClient is stubbed until the API lands.
