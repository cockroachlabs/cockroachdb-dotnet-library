HTTP-backed IMcpClient speaking the MCP Streamable HTTP transport (spec 2025-06-18). Lazily performs the initialize handshake before the first tools call, echoes the server-assigned Mcp-Session-Id and the MCP-Protocol-Version header, and handles both application/json and text/event-stream responses. Responses are parsed with JsonDocument by field name. Construct with Create(string, string) in production, or inject an HttpClient backed by a fake handler in tests.
