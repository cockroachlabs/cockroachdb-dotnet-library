Shared helper that applies a Cockroach vCluster VirtualClusterBinding to a connection as transaction-scoped session settings. Both VirtualClusterMiddleware and integration tests use this exact code path so behavior is verified end-to-end.

SET LOCAL scopes the tags to the current transaction so pooled connections are not polluted for the next borrower.
