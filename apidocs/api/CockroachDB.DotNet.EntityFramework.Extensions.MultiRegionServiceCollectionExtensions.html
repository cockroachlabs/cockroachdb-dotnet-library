CockroachDB.DotNet.EntityFramework.Extensions

CockroachDB.DotNet.EntityFramework.dll

EF-layer registration for CockroachDB. Registering a context through these helpers turns the startup multi-region check on by default (mirroring the Spring starter, which gates its autoconfig on Hibernate being present): the check lives in the EF integration, so an application that uses only the raw Core/Npgsql pipeline pulls no EF Core and gets no check — it has no entity model to check. CockroachDB:MultiRegion:Mode=none turns the check off.

AddCockroachDBMultiRegionCheck(IServiceCollection)

Registers the startup multi-region check explicitly, for every registered EF Core DbContext. Normally unnecessary — AddCockroachDBDbContext<TContext>(IServiceCollection, Action<DbContextOptionsBuilder>) and AddCockroachDBDbContextFactory<TContext>(IServiceCollection, Action<DbContextOptionsBuilder>) already turn it on — but useful when a context is registered with plain AddDbContext. Safe to call more than once.
