A CockroachDB Cloud cluster (control-plane view).

ContinuumCloudHealthCheck

Health check for the Cockroach Continuum Cloud control-plane connection. Healthy when clusters can be listed; the result details report whether the client is simulated or live and the cluster count.

ContinuumCloudServiceCollectionExtensions

DI registration for the Continuum Cloud control-plane surface.

HttpCloudClient

HTTP-backed ICloudClient that talks to the real CockroachDB Cloud API using a service-account Bearer token. Responses are parsed with JsonDocument by their documented (snake_case) field names, so the client is independent of any serializer naming configuration. Construct with Create(string, string) in production, or inject an HttpClient backed by a fake handler in tests.

MetricExport

Typed builders for the three metric-export sinks. Each returns a MetricExportConfig ready to pass to ConfigureMetricExportAsync(string, MetricExportConfig, CancellationToken), so callers don't have to remember the Cloud API's field names. The raw Settings dictionary remains available for sinks or fields not covered here (e.g. Azure Monitor).

MetricExportConfig

Metric-export configuration. Settings carries the target-specific fields (datadog: site, api_key; cloudwatch: role_arn, etc.).

NpgsqlSqlRunner

ISqlRunner backed by an Npgsql data source.

SimulatedCloudClient

In-memory ICloudClient for development and tests. Serves a small canned set of clusters and records metric-export calls. Selected automatically when no Cloud API key is configured.

VirtualCluster

A Cockroach virtual cluster. RoutingId is used when connecting (it differs from the control-plane cluster ID); see RoutingConnString(string, string).

VirtualClusterManager

Manages Cockroach virtual-cluster lifecycle over a SQL connection using the CREATE / SHOW / DROP VIRTUAL CLUSTER statements (these require a Continuum-enabled cluster). Names are validated before interpolation into DDL.
