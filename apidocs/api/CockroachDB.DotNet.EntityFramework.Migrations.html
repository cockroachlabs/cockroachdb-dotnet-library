CockroachDBHistoryRepository

History repository for CockroachDB that disables migration database locking.

CockroachDB does not support PostgreSQL advisory locks (pg_advisory_lock) or LOCK TABLE statements. EF Core 10+ requires IMigrationsDatabaseLock for concurrent migration safety. This implementation provides a no-op lock, relying on CockroachDB's SERIALIZABLE isolation for conflict handling.

Migration coordination should happen at the deployment level (e.g., single-pod deploy, migration job, deployment gate).

CockroachDBMigrationsSqlGenerator

Migration SQL generator for CockroachDB, extending Npgsql's PostgreSQL generator with CockroachDB-specific DDL overrides: computed columns (STORED only), JSON default fix, and unique_rowid() support.

CockroachDBNoopDatabaseLock

No-op database lock for CockroachDB — advisory locks are not available.
