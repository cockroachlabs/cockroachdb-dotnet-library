Namespace CockroachDB.DotNet.Continuum.VCluster

Classes

VirtualClusterAttribute

Tags the annotated method's work for a Cockroach vCluster so it is isolated on shared capacity. The vCluster name is applied as SET LOCAL application_name for the transaction, so the workload is attributable in the DB Console and logs.

Combine with WorkloadAttribute to also assign a priority/QoS class.

Scope (v1): workload tagging. Routing to a distinct vCluster endpoint is platform-dependent and is not performed by the library. Because .NET has no runtime method interception here, the attribute is a declarative marker; the runtime application path is VirtualClusterContext plus VirtualClusterMiddleware (or OnVirtualCluster(...)).

VirtualClusterBinding

An immutable Cockroach vCluster binding: a workload name and an optional priority. When Priority is null only the application_name tag is applied.

VirtualClusterCommands

Shared helper that applies a Cockroach vCluster VirtualClusterBinding to a connection as transaction-scoped session settings. Both VirtualClusterMiddleware and integration tests use this exact code path so behavior is verified end-to-end.

SET LOCAL scopes the tags to the current transaction so pooled connections are not polluted for the next borrower.

VirtualClusterContext

AsyncLocal<T>-based Cockroach vCluster context for programmatic use, mirroring RegionContext. When set, VirtualClusterMiddleware (and the OnVirtualCluster(...) execution wrapper) apply the tag/QoS to the transaction. Flows correctly across async/await continuations.

VirtualClusterExecutorExtensions

Fluent, programmatic Cockroach vCluster execution: mirrors the template's InRegion(...). Binds a vCluster name/priority for the duration of the operation so VirtualClusterMiddleware tags it.

await executor.OnVirtualCluster("analytics", WorkloadPriority.Low)
              .ExecuteAsync(() => repository.RunReportAsync());
VirtualClusterMiddleware

Pipeline middleware that applies Cockroach vCluster workload tagging. Mirrors RegionMiddleware: when a binding is in scope (via the OnVirtualCluster(...) wrapper, VirtualClusterContext, or a binding placed on the context) it opens a transaction and issues the SET LOCAL application_name / SET LOCAL default_transaction_quality_of_service statements so the workload is attributable, then proceeds.

Register with pipeline.UseVirtualCluster().

WorkloadAttribute

Assigns a Cockroach vCluster workload priority to the annotated method, mapped to CockroachDB admission-control quality-of-service and applied as SET LOCAL default_transaction_quality_of_service for the transaction.

Most useful alongside VirtualClusterAttribute. Without a vCluster binding (attribute or programmatic VirtualClusterContext) there is nothing for the QoS to attach to.

WorkloadPriorityExtensions

Maps a WorkloadPriority to its CockroachDB default_transaction_quality_of_service value.
